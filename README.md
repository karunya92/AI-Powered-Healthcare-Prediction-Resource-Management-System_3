# AI-Powered-Healthcare-Prediction-Resource-Management-System_3# AI-Powered Healthcare Prediction & Resource Management System

## Project Overview

The AI-Powered Healthcare Prediction & Resource Management System is an intelligent healthcare platform designed to improve patient care and optimize hospital operations using Artificial Intelligence and Machine Learning.

The system helps hospitals:

* Predict disease risks
* Analyze patient health records
* Recommend treatments
* Forecast hospital resource requirements
* Manage beds, doctors, staff, and equipment
* Generate analytical reports and dashboards

## Installation

1. Clone the repository

git clone <repository-url>

2. Navigate to project folder

cd AI_HEALTHCARE_SYSTEM

3. Install dependencies

pip install -r requirements.txt

4. Run the application

streamlit run app.py
